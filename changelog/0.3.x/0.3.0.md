# 0.3.0 — 2026-09-24

## Added

- **`notes` on `npi_lookup_taxonomy` mode `get` and `npi://taxonomy/{code}`** — the trimmed NUCC Notes cell, rendered in the `get` text output; absent when the cell is empty, and omitted from `resolve`/`browse` entries ([#11](https://github.com/cyanheads/npi-providers-mcp-server/issues/11)).
- **`status` (`active`/`inactive`) and `replacedBy` on every taxonomy entry** — `replacedBy` is the active replacement code NUCC names for an inactive code; both render in every mode's text output ([#16](https://github.com/cyanheads/npi-providers-mcp-server/issues/16)).
- **Resolver aliases for terms NUCC spells differently** — `orthopedist`/`orthopedic` → Orthopaedic Surgery, `neurosurgeon` → Neurological Surgery, `cardiac surgeon` → Thoracic Surgery (Cardiothoracic Vascular Surgery), `speech therapist` → Speech-Language Pathologist, `primary care doctor` → Family Medicine and Internal Medicine ([#22](https://github.com/cyanheads/npi-providers-mcp-server/issues/22)).

## Changed

- **`resolve` never returns inactive NUCC codes, and neither does `npi_search_providers` `specialty` resolution** — a term that matched only inactive codes now fails with `no_match` / `unresolved_specialty`, naming those codes and their replacements. `get`, `browse`, and `npi://taxonomy/{code}` still return inactive codes, flagged ([#16](https://github.com/cyanheads/npi-providers-mcp-server/issues/16)).
- **Bundled NUCC taxonomy refreshed v25.0 → v26.1** — 883 codes (879 before), 28 of them inactive. v26.1 drops the `Deactivated - ` display-name prefix; read `status` instead ([#16](https://github.com/cyanheads/npi-providers-mcp-server/issues/16)).
- **A bare specialist term resolves to its representative general entry first** — `oncologist` → Medical Oncology, `endocrinologist` → Endocrinology, Diabetes & Metabolism, `pharmacist` → Pharmacist, and likewise for `hematologist`, `radiologist`, `pathologist`, `geriatrician`. Only single-term queries are reordered; no match is added or removed ([#10](https://github.com/cyanheads/npi-providers-mcp-server/issues/10)).

## Fixed

- **`resolve` matches query terms at word starts, not inside unrelated words** — `dentist` no longer hits "Independent", `urologist` no longer hits Neurology; compounds such as Neuroradiology and Cytopathology still match `radiologist` and `pathologist` ([#20](https://github.com/cyanheads/npi-providers-mcp-server/issues/20)).
- **A stripped stop word that names the entry's own specialty counts in ranking** — `physician assistant` leads with Physician Assistant, not Dental Assistant ([#21](https://github.com/cyanheads/npi-providers-mcp-server/issues/21)).
- **`therapist` no longer resolves to Therapeutic Radiology** — a bare `therapist` matches the word "Therapist" whole; qualified queries such as `occupational therapist` keep their matches ([#24](https://github.com/cyanheads/npi-providers-mcp-server/issues/24)).
- **Pediatric variants no longer lead `sports medicine` and `sleep medicine`** — a Pediatrics-classified entry ranks after its adult counterparts unless the query names pediatrics ([#25](https://github.com/cyanheads/npi-providers-mcp-server/issues/25)).
