# 0.1.8 — 2026-08-24

## Added

- **Cache hints** — tool and resource catalogs advertise a one-hour public TTL, while the bundled NUCC taxonomy resource advertises a one-day public TTL to 2026-07-28 clients.
- **Correctness test lanes** — smoke, integration, fuzz, and Istanbul coverage projects exercise every public primitive, sparse NPPES payloads, strict arguments, pagination disclosure, and existing issue boundaries.

## Changed

- **MCP SDK v2 compatibility** — HTTP serves per-request protocol revision 2026-07-28 while retaining the 2025-11-25 sessionful path; undeclared root tool arguments are rejected by name, and advertised tool errors include structured envelopes.
- **`npi_lookup_taxonomy` input** — each `resolve`, `get`, and `browse` mode now advertises only its valid arguments through a discriminated union, with semantic validation errors for blank values.
- **NPPES request context** — retries and upstream fetches now receive the handler context directly, preserving request correlation while returning semantic field failures as `ValidationError`.
- **Session mode** — `.env.example`, the Docker image, and the README explicitly pin `MCP_SESSION_MODE=stateless`; the framework schema default remains `auto`, which resolves to stateful when no explicit mode is set.
- **Scaffold maintenance** — synced framework scripts and agent skills, Bun 1.4 container pins, optional-peer pruning, TypeScript 7 typechecking across source and tests, current community-health files, and canonical package metadata.
