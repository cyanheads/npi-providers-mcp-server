# 0.5.0 — 2026-10-25

## Added

- Added the npi-providers-guide skill, served as skill://npi-providers-guide/SKILL.md.
- **First-name aliases:** optional `use_first_name_alias` controls upstream variants; `appliedFirstNameAlias` reports the effective setting. ([#39](https://github.com/cyanheads/npi-providers-mcp-server/issues/39))
- **Agent Plugins:** root `plugin.json` and `mcp.json` provide the standard plugin entry points alongside the existing client overlays.

## Changed

- **Limits:** oversized search and taxonomy limits clamp to 200 and 50 with notices, logs and a counter; `NPI_CLAMP_LIMITS=false` restores strict bounds. ([#37](https://github.com/cyanheads/npi-providers-mcp-server/issues/37), [#34](https://github.com/cyanheads/npi-providers-mcp-server/issues/34))
- **Provider batches:** accept 100 raw entries, deduplicate and validate before ten lookups, and retain every invalid NPI and any `unprocessed` remainder in results and errors. ([#40](https://github.com/cyanheads/npi-providers-mcp-server/issues/40))
- **NUCC text:** convert known HTML breaks and lists to readable text while preserving other source text. ([#38](https://github.com/cyanheads/npi-providers-mcp-server/issues/38))
- **Skill delivery:** include the guide in npm, Docker, plugin and MCPB installs.
- **Development tooling:** sync framework skills, packaging and audit checks, issue templates, and installation documentation; set the package release-age floor to one day.

## Fixed

- **Taxonomy modes:** advertise one flat input object so clients retain every mode; validate mode-specific arguments before applying defaults. ([#34](https://github.com/cyanheads/npi-providers-mcp-server/issues/34))
- **NUCC section:** remove the incorrect equivalence between taxonomy section and NPI entity type. ([#36](https://github.com/cyanheads/npi-providers-mcp-server/issues/36))
- **MCPB bundles:** retain executable dependency skill modules while pruning development documentation and build-only files.
